# Panduan Menaruh Foto & Lagu MP3 Undangan

Anda dapat menaruh file foto dan musik pada folder ini:

### 1. Folder Foto
Taruh foto-foto pernikahan di:
`/public/assets/images/`
Contoh penamaan:
- `groom.jpg` (Foto mempelai pria)
- `bride.jpg` (Foto mempelai wanita)
- `prewed-1.jpg`, `prewed-2.jpg`, dst. (Foto galeri)

Setelah ditaruh di folder tersebut, foto dapat dipanggil di website dengan path:
`"/assets/images/nama_foto.jpg"`

### 2. Folder Musik MP3
Taruh file lagu di:
`/public/assets/audio/`
Contoh:
- `wedding-song.mp3`

Dapat dipanggil di website dengan path:
`"/assets/audio/wedding-song.mp3"`

---

### Cara Lain yang Lebih Cepat (Langsung Lewat Layar Web):
Anda juga bisa langsung mengunggah foto atau file MP3 langsung dari tampilan website:
1. **Ganti Lagu MP3**: Klik tombol ikon Gerigi (⚙️) di sebelah pemutar musik piringan hitam di pojok kanan bawah, lalu klik tombol **"Upload Lagu MP3 Anda"**.
2. **Tambah Foto ke Galeri**: Di bagian Galeri Foto, klik tombol **"+ Tambah Foto Asset"** untuk memilih foto langsung dari HP atau komputer Anda.
3. **Ganti Foto Profil Mempelai**: Di bagian profil mempelai, pilih mode "Foto Prewedding" lalu klik ikon kamera untuk mengganti foto.
